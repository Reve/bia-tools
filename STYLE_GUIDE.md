# Visual Style Guide

## Palette

### Base Neutrals
- Ink: #0F172A (primary text)
- Slate: #334155 (secondary text)
- Mist: #E2E8F0 (borders, dividers)
- Paper: #F8FAFC (page background)

### Accent Colors
- Cobalt: #2563EB (primary action, links)
- Emerald: #10B981 (valid state)
- Amber: #F59E0B (warning or attention)
- Rose: #EF4444 (invalid state)


## Typography
- Primary font: Inter (fallback: "Helvetica Neue", Arial, sans-serif)
- Headings: 600 weight, tight letter spacing
- Body: 400 weight, 1.6 line height


## Spacing & Layout
- Base spacing unit: 8px
- Section padding: 32px vertical, 24px horizontal
- Card padding: 20px
- Max content width: 960px


## Components

### Cards
- Background: Paper
- Border: 1px solid Mist
- Border radius: 12px
- Shadow: subtle, 0 8px 24px rgba(15, 23, 42, 0.08)

### Buttons
- Primary: Cobalt background, white text
- Secondary: transparent background, Cobalt border, Cobalt text
- Focus state: 2px solid Amber outline

### Badges
- Valid: Emerald background, white text
- Invalid: Rose background, white text
- Neutral: Mist background, Slate text


## Iconography & Illustrations
- Use simple line icons with consistent stroke width.
- Avoid heavy gradients; prefer flat fills.


## Motion
- Use 150–250ms transitions for state changes.
- Animate validity changes with a gentle fade or color shift.
